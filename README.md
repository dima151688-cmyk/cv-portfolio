# CV Portfolio — GitHub Pages

Готовые файлы для публикации на GitHub Pages. Содержимое сайта взято из предоставленного HTML; изображения и PDF вынесены из base64 в папку `assets/` для более быстрой загрузки.

## Как обновить существующий сайт

1. Откройте https://github.com/dima151688-cmyk/cv-portfolio
2. Нажмите **Add file → Upload files**.
3. Распакуйте архив и перетащите **содержимое** этой папки, а не ZIP: `index.html`, папку `assets`, `.nojekyll` (и при желании README.md).
4. Подтвердите изменения через **Commit changes**. Если GitHub предлагает создать новую ветку, создайте её и затем **Compare & pull request → Merge pull request**.
5. Проверьте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save** (если так уже настроено, не меняйте).
6. Через несколько минут откройте https://dima151688-cmyk.github.io/cv-portfolio/

Важно: если в корне репозитория уже есть `index.html`, при добавлении нового файла нужно именно заменить старый.

## Приватность

Сайт и содержимое `assets/` будут публичными. Проверьте сканы дипломов, контакты и любые личные данные перед загрузкой. Для предотвращения случайного раскрытия приватных сведений не загружайте сюда секреты и файлы с паролями.
